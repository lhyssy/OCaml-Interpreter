## 项目代码运行方法

本项目为dune项目，可以提供的项目参数如下：

- `-i <filename> `：将`filename`作为输入流
- `-o <filename> `：将`filename`作为输出流
- `-ast `：将解析得到的AST输出到终端
- `-ir `：将解析得到的IR输出到终端
- `-opt`：启用优化程序（被忽略）

示例：

如下代码为默认的结构，从标准输入流读取，并输出到标准输出流

```bash
dune exec interpreter_project
```

如下代码从文件中读取并且读出到文件，且输出IR结构

```bash
dune exec interpreter_project -- -i test/06_continue.tc -o test_results/res.s -ir
```

如下代码从文件中读取并且读出到文件，且输出AST结构

```bash
dune exec interpreter_project -- -i test/06_continue.tc -o test_results/res.s -ast
```

## 项目代码测试方法

你可以使用如下指令对于`test/`文件夹中存放的所有文件（不包含旧文件）进行批量测试：

```bash
dune runtest
```

如果能够生成所有代码，将会声明如下提示：

```
所有测试文件已编译完成，结果存储在 test_results 目录中
请自行使用venus插件测试实际的代码运行结果.
```
